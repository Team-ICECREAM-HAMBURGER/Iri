# 이리(Iri)
![iri_Title](https://github.com/user-attachments/assets/fa46de8c-558f-45da-82bf-56e742f4d803)
> ***“우리는 광기의 시대에 살고 있다.”***
<br/>

\<이리>는 냉전 시대를 배경으로 ‘인간성’을 탐구하는 대체 역사물 누아르 스릴러 퍼즐 게임입니다.

플레이어는 상부의 명령을 수행하는 ‘역사감독관’이 되어 열차 승객들을 검문하며, 다양한 음모와 사건에 휘말리게 됩니다.

선택에 따라 변화하는 몰입감 높은 ‘인터랙티브 서사’의 완성을 목표로 개발 중입니다.
